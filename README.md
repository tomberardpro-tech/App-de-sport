# Salle

Mon suivi de salle et de diète, sans abonnement.

- **Onboarding** en 5 étapes → cible de calories calculée (Mifflin-St Jeor + activité + objectif)
- **Tableau de bord** en widgets : on les déplace, retire, redimensionne (P / M / G)
- **Machines** : liste de départ + machines perso avec photo, favoris, séries poids × reps, records, courbe de progression, réglages
- **Diète** : repas du jour, plats/shakers composés avec total automatique, scan code-barres (Open Food Facts)
- **Historique** : séances et pesées
- Données uniquement sur le téléphone, avec sauvegarde / restauration en fichier

## Lancer

```bash
npm install
npm run dev
```

## Installer sur le téléphone

Après `npm run build`, héberger le dossier `dist/` (GitHub Pages, Netlify…), ouvrir l'adresse sur le téléphone puis « Ajouter à l'écran d'accueil ».

Voir `DESIGN_SYSTEM.md` pour les règles d'interface.
